# kaygaaf/homebrew-tap

Homebrew tap for my tools. The casks in here get written by GoReleaser when I cut a release, so don't edit them by hand.

```sh
brew install kaygaaf/tap/tattlr
```

That's the same as `brew tap kaygaaf/tap` followed by `brew install tattlr`.

Something broken? Open an issue on the tool's own repo, like [kaygaaf/tattlr](https://github.com/kaygaaf/tattlr/issues).
